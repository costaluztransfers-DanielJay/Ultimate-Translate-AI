Ultimate Translate AI creates linked translated copies of WordPress pages/posts and translates Elementor content through DeepL, Google Translate, OpenAI, Gemini or Claude.

== MVP features ==
* Admin settings page.
* Languages list.
* API provider selection.
* Post/page language metadata.
* Draft translation copy creation.
* Elementor _elementor_data recursive text translation.
* Basic Yoast SEO meta translation.
* Frontend shortcode: [utai_language_switcher].
* Basic hreflang tags for published translation groups.

== Important ==
This is an MVP. Test first on staging. Do not run on production without a backup.
